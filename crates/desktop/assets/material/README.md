# Material Symbols

All application icons use the official offline catalog supplied by `iced-m3`'s
`material-symbols` feature, not application-owned SVGs or icon fonts. Artwork is
Outlined, weight 400, grade 0; navigation uses filled artwork for the selected
destination. Terminal buttons use the optical-size-20 artwork at 20 logical
pixels; other icons use optical size 24 at 24 logical pixels.

The included Apache 2.0 `LICENSE` and upstream `NOTICE` cover Google's bundled
Material Symbols. `scripts/package_mac.sh` copies both to
`Homecloud.app/Contents/Resources/licenses/material-symbols/`. Keep these notices
in sync with `iced_m3::material_symbols::{LICENSE, NOTICE}` when upgrading.
