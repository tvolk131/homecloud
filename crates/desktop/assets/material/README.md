# Material Symbols

These unmodified 24px outlined SVGs come from Google's
[Material Symbols repository](https://github.com/google/material-design-icons/tree/master/symbols/web).
They are distributed under the included Apache 2.0 license.

The terminal, play, stop, add and edit controls use these assets. Existing sidebar
icons remain separate pending upstream iced-m3 icon catalog integration.
